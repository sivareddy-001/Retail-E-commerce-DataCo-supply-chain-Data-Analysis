Retail E-commerce DataCo Supply Chain Data Analysis
📌 Project Overview

This project focuses on analyzing DataCo Supply Chain and E-commerce data to identify patterns in sales, orders, shipping, customers, products, and supply-chain performance.

The project includes raw data, preprocessing/cleaning steps, and a cleaned dataset prepared for further analysis and visualization.

🎯 Objectives
Analyze e-commerce sales and order data
Understand customer purchasing patterns
Analyze product and category performance
Evaluate shipping and delivery performance
Identify supply-chain trends and issues
Clean and preprocess raw datasets
Prepare reliable data for analytics and visualization
